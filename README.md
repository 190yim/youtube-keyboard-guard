# YouTube Keyboard Guard

🛡️ A lightweight browser extension that prevents accidental YouTube keyboard shortcuts.

YouTube Keyboard Guard helps prevent accidental key presses from triggering unwanted actions while watching videos.

## ✨ Features

- 🛡️ Blocks accidental YouTube keyboard shortcuts
- 🇫🇷 AZERTY keyboard support
- 🎵 Compatible with YouTube and YouTube Music
- 🔘 ON/OFF protection switch
- 💾 Saves your protection setting
- ⚡ Lightweight and simple
- 🎨 Clean and minimal interface

## 🛠️ Technologies

- JavaScript
- HTML
- CSS
- Chrome Extensions Manifest V3

## 📦 Installation

### Development

1. Download or clone this repository.
2. Open `brave://extensions/` or `chrome://extensions/`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the project folder.
